# Architecture

## Scientific question

Given a protein binding pocket and a ligand's 2D/topological structure, can a
conditional generative model produce 3D ligand binding poses (atomic
coordinates) that are physically plausible and close to the experimentally
observed pose? This project studies that question at small scale using
equivariant geometric deep learning and Flow Matching, rather than
traditional search-based docking.

## Input / output

- **Input:** a protein pocket structure (fixed, from a co-crystal structure)
  and a ligand's molecular graph (atom types, bonds, formal charges) with an
  arbitrary initial 3D conformer or pure noise.
- **Output:** 3D coordinates for every ligand (heavy) atom, representing a
  predicted binding pose within the given pocket.

The protein is treated as a fixed conditioning context; only ligand
coordinates are generated.

## Protein representation

The protein is reduced to a **pocket graph**: residues within a cutoff radius
of the known binding site are kept as nodes (coarse, one node per residue via
Cα coordinate, extendable to backbone/sidechain atoms later), with edges
connecting spatially nearby residues. Node features encode residue identity;
edge features encode inter-residue distance. This keeps the graph small and
tractable for a research-scale model rather than encoding the full protein.

## Ligand representation

The ligand is represented as a **molecular graph** parsed with RDKit: atoms
are nodes (atomic number, formal charge, hybridization, aromaticity), bonds
are edges (bond order, ring membership). 3D coordinates are treated as a
per-node feature that evolves under the generative process, decoupled from
the fixed topological graph.

## Flow Matching objective

We use **Conditional Flow Matching** (Lipman et al.) with a simple linear
interpolation path between a noise distribution and the data distribution:

```
x_t = (1 - t) * x0 + t * x1,   t ∈ [0, 1]
x0 ~ prior (e.g. Gaussian, or pocket-centered noise)
x1  = ground-truth ligand atom coordinates (data)
```

The target conditional vector field for the linear path is constant in `t`:

```
u_t(x_t | x0, x1) = x1 - x0
```

A neural network `v_theta(x_t, t, pocket, ligand_graph)` — built from
equivariant graph layers so it respects rotation/translation symmetry of
3D coordinates — is trained to regress this target vector field via
mean-squared error, conditioned on the fixed protein pocket and the ligand's
molecular graph. At inference time, poses are generated by numerically
integrating `dx/dt = v_theta(x_t, t, ...)` from `t=0` to `t=1`.

This project currently implements only the mathematical scaffolding for the
path/target (see `diffusion/flow_matching.py`); the equivariant vector-field
network itself is a stub pending later stages.

## Evaluation metrics

- **RMSD** between generated and crystallographic ligand pose, after optimal
  rigid alignment of the pocket (protein held fixed, so alignment is
  typically not needed if the pocket frame is shared).
- **Pose success rate**: fraction of generated poses with RMSD below a
  threshold (2.0 Å, matching common docking-literature convention).
- Later stages: physical plausibility checks (steric clashes, bond length/
  angle sanity) and, once affinity prediction is added, ranking metrics
  (e.g. Spearman correlation with experimental binding affinity).

## Planned experiment stages

1. **Data**: curate a small PDBBind subset and preprocessing pipeline
   (pocket extraction, RDKit parsing, train/val/test split). No download yet.
2. **Representation**: implement protein pocket graph and ligand molecular
   graph construction as PyTorch Geometric `Data` objects.
3. **Model**: implement a minimal equivariant Flow Matching vector-field
   network (small hidden size, few layers) as a first inspectable baseline.
4. **Generation**: integrate the learned vector field to sample ligand poses
   from noise, conditioned on a pocket.
5. **Evaluation**: compute RMSD and pose-success-rate on held-out complexes.
6. **Scale-up (later)**: larger PDBBind subset/full dataset, binding affinity
   prediction head, and virtual screening over a candidate ligand library.
